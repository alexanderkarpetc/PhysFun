# Binny — сжатый концепт, разрезанный на слои

Исходный концепт `BinnyConcept.png` (1024×1024) был пиксель-артом, отрисованным
блоками ≈19 px, то есть родная сетка — **54×54**. Сняли её модой цвета по каждой
клетке, подрезали по контенту → `Binny_Master.png` **42×47**, из них
**шасси 41 px** в высоту. Никакой перерисовки: все пиксели ниже — из оригинала.
Сам файл 1024×1024 после этого удалён, мастером считается `Binny_Master.png`.

Проверка: слои, сложенные обратно, совпадают с оригиналом **пиксель в пиксель
(0 расхождений)**.

## Лица

`Angry` вырезана из концепта как есть. Остальные собраны из её же пикселей
(те же два цвета `#881b11` / `#72281b`, та же сетка): `Sad` — те же брови,
отражённые по вертикали; `Happy` — тот же рот углами вверх; дальше `Mad`,
`Neutral`, `Talk01/02`, `Surprised`, `Sleep`, `Dead`, `Glitch`.

Talk01/Talk02 гонять ~8 fps под болтовню. Glitch — один кадр помех, годится
на получение урона.

## Движение

- шестерня крутится со скоростью, пропорциональной скорости перемещения;
  вторую поставить зеркальной на правый под
- пламя: 4 кадра по кругу, ~12 fps, пока летит
- крошки сыпать на удар / изредка в покое
- лицо по состоянию: Angry в покое → Surprised в полёте → Happy на победе →
  Talk при разговоре → Glitch на уроне

## Пиктограммы на экран

`Emotes/Binny_Emote_*.png` — то же окно 14×11, но вместо эмоции экран показывает
картинку. Для кода это просто другой спрайт в том же слоте.

Тон в четыре оттенка красного: `#56140b` низ и борозды, `#881b11` (родной цвет
лица) основной, `#c64628` освещённая кромка, `#ff8a5c` искра. Правило простое —
экран светит сверху: верхняя кромка светлая, нижняя тёмная. Тёмный кант по всему
контуру не годится: на чёрном экране он невидим и просто съедает силуэт.

| Файл | Что |
|---|---|

| `Poop` | кучка |
| `Skull` | череп |
| `Unimpressed` | «ну-ну», полуприкрытые глаза |
| `ThumbUp` / `ThumbDown` | лайк / дизлайк |

## UI — как он разговаривает

`UI/Binny_Dialogue.html` — кликабельный концепт диалогового окна: пиксельная
рамка, портрет = его же экран, текст набирается посимвольно, лицо шевелится
(`Talk01`/`Talk02`) и встаёт на эмоцию реплики в конце. Два режима размещения:
пузырь с хвостиком над ним и нижняя панель. Открывается двойным кликом
(шрифт Pixelify Sans тянется из Google Fonts, нужен интернет).

Чтобы посмотреть через локальный сервер (иначе всё работает и так):
`preview_start` → конфиг `binny-concept` в `.claude/launch.json`, дальше
`http://localhost:8777/UI/Binny_Dialogue.html`.

Пиксельные ассеты окна лежат рядом:

| Файл | Размер | Что это |
|---|---|---|
| `UI/Binny_DialogFrame.png` | 24×24, слайс 5 | 9-slice рамка окна |
| `UI/Binny_NamePlate.png` | 16×12, слайс 5 | 9-slice плашка под имя |
| `UI/Binny_DialogTail.png` | 9×6 | хвостик пузыря |
| `UI/Binny_ContinueArrow.png` | 7×5 | мигающая стрелка «дальше» |
| `UI/Binny_ChoiceCursor.png` | 5×7 | курсор выбора варианта |

Классы в HTML названы так же, как будут в USS (`.dlg`, `.dlg__name`,
`.dlg__portrait`, `.dlg__text`, `.dlg__next`), структура повторяет будущий UXML —
таблица соответствий есть в самом файле внизу страницы.

## В игре

`PhysFun/Binny/Build Binny` собирает префаб `Assets/Resources/Prefabs/Binny.prefab`
из тех же слоёв — никакого листа и никаких клипов, сборка и есть префаб. Заодно
чинит импорт всем png в этой папке (кроме `UI/`): Point, без сжатия, PPU 41.
`PhysFun/Create/Binny` ставит его в открытую сцену. Пересобирать можно поверх:
префаб перезаписывается, ссылки на него живут.

Иерархия: `Binny` (кинематичное тело, бокс по корпусу, `BinnyController`,
`SortingGroup`) → `View` (`BinnyView`) → `Thrust_L/R`, `Body`, `Gear_L/R`, `Face`.
Якоря частей взяты из таблицы выше и лежат константами в `BinnyBuilder`; правая
шестерня — та же, отзеркаленная по кадру (её дырки в концепте нет, нарисована
была только левая).

Что он умеет сейчас: висит там, где поставили, покачиваясь; по клавише **B**
подлетает к игроку с той стороны, с которой был, тормозит и встаёт на месте —
и всё, дальше не следует. Лицо: Angry в покое, Surprised в полёте, Happy
секунду после прилёта. Шестерни крутятся от скорости (с шагом 15°, чтобы не
мылились), пламя горит только в полёте.

Тело кинематичное: он держит точку и расталкивает мусор, а не болтается от
него, и качка идёт через физическое тело — коллайдер всегда там же, где
картинка, чтобы потом в него было чем попадать.

Диалогов, эмоций по реплике и переработки закинутого пока нет — под них есть
`BinnyController.SendTo/Halt`, `BinnyView.SetFace` и список лиц по `BinnyFace`.
Высота — 1 юнит (PPU 41 из раздела ниже), игрок 0.8, враги 0.9; если великоват,
это одна константа `PixelsPerUnit` в `BinnyBuilder`.

## Импорт в Unity

Sprite (2D and UI) · Sprite Mode **Single** · Filter Mode **Point (no filter)** ·
Compression **None** · Pixels Per Unit **41** · пивот **Center** у всех частей.

Пивоты одинаковые нарочно: тогда позиция части — это её центр, и вся раскладка
сводится к разнице центров с якорями из таблицы выше. Всё это ставит
`Build Binny`, руками в инспекторе трогать нечего.

## Пересборка

Скрипты лежат вне проекта (scratchpad сессии): `shrink.py` снимает родную
сетку, `pack.py` режет слои и собирает листы.
