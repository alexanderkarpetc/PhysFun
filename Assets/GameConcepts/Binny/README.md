# Binny — сжатый концепт, разрезанный на слои

Исходный концепт `BinnyConcept.png` (1024×1024) был пиксель-артом, отрисованным
блоками ≈19 px, то есть родная сетка — **54×54**. Сняли её модой цвета по каждой
клетке, подрезали по контенту → `Binny_Master.png` **42×47**, из них
**шасси 41 px** в высоту. Никакой перерисовки: все пиксели ниже — из оригинала.
Сам файл 1024×1024 после этого удалён, мастером считается `Binny_Master.png`.

Проверка: слои, сложенные обратно, совпадают с оригиналом **пиксель в пиксель
(0 расхождений)**.

## Лица

`Angry` вырезана из концепта как есть. Остальные собраны из её же пикселей
(те же два цвета `#881b11` / `#72281b`, та же сетка): `Sad` — те же брови,
отражённые по вертикали; `Happy` — тот же рот углами вверх; дальше `Mad`,
`Neutral`, `Talk01/02`, `Surprised`, `Sleep`, `Dead`, `Glitch`.

Talk01/Talk02 гонять ~8 fps под болтовню. Glitch — один кадр помех, годится
на получение урона.

## Движение

- шестерня крутится со скоростью, пропорциональной скорости перемещения;
  вторую поставить зеркальной на правый под
- пламя: 4 кадра по кругу, ~12 fps, пока летит
- крошки сыпать на удар / изредка в покое
- лицо по состоянию: Angry в покое → Surprised в полёте → Happy на победе →
  Talk при разговоре → Glitch на уроне

## Импорт в Unity

Sprite (2D and UI) · Filter Mode **Point (no filter)** · Compression **None** ·
Pixels Per Unit **41** · пивот Bottom у тела, Center у шестерни,
Top-Center у пламени.

## Пересборка

Скрипты лежат вне проекта (scratchpad сессии): `shrink.py` снимает родную
сетку, `pack.py` режет слои и собирает листы.
